ARGO S3 — объектное хранилище с S3-совместимым API, разворачивается поверх кластера ARGO Storage. Подходит для резервного копирования, архивации и хранения неструктурированных данных приложений.

## Совместимость

Поддерживается работа с существующими S3-клиентами и SDK без модификации кода приложения — достаточно указать эндпоинт кластера ARGO S3.

```bash
aws --endpoint-url https://s3.example.local s3 ls
```

## Основные сущности

- **Bucket** — контейнер для объектов с настраиваемой политикой доступа
- **Object** — единица хранения с произвольными метаданными
- **Access Key / Secret Key** — пара для аутентификации клиента

Документация по установке и тонкой настройке политик доступа появится в следующих обновлениях раздела.
