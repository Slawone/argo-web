Минимальная конфигурация кластера — три узла. Ниже — базовый порядок развёртывания одного узла перед объединением в кластер.

1. Установите базовую ОС из списка поддерживаемых (Astra Linux, ROSA, ALT Linux).
2. Разверните пакет `argo-storage-node` на узел.
3. Инициализируйте узел и присоедините его к кластеру:

```bash
argoctl node init --role storage
argoctl cluster join --token <CLUSTER_TOKEN>
```

4. Проверьте статус узла:

```bash
argoctl node status
```

> Перед вводом узла в продуктивную эксплуатацию убедитесь, что сетевые интерфейсы для кластерного трафика настроены на отдельный VLAN — это снижает риск деградации при пиковой нагрузке.

После инициализации всех узлов кластер готов к созданию пулов хранения через панель управления.
