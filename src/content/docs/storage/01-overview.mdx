ARGO Storage — программно-определяемая система хранения данных для корпоративных и государственных заказчиков. Поддерживает блочный, файловый и объектный доступ, работает на сертифицированном отечественном оборудовании и включена в Единый реестр российского ПО.

## Из чего состоит система

| Компонент | Назначение |
| --- | --- |
| Узел (Node Appliance) | Обрабатывает ввод-вывод, хранит данные и метаданные |
| Контроллер | Управляет кластером узлов, балансирует нагрузку |
| Панель управления | Веб-интерфейс и CLI для администрирования |

## Ключевые возможности

- Многоконтроллерная архитектура для отказоустойчивости
- Механизмы компрессии и кэширования горячих данных
- Снапшоты и репликация между узлами
- Контроль целостности данных на уровне блоков

```bash
argoctl cluster status
```
